ВИКТОРИНА — учебный проект Android Studio

Реализовано:
- MainActivity: экран приветствия, описание и кнопка начала.
- QuizActivity: надпись «Вопрос N из 5», вопрос и 4 варианта ответа.
- Переход между экранами, 5 вопросов, подсчёт правильных ответов.
- Оба экрана используют ConstraintLayout.

Как открыть:
1. Распакуйте архив QuizApp.zip.
2. В Android Studio выберите File -> Open и укажите папку QuizApp.
3. Дождитесь Gradle Sync (понадобится интернет для Gradle и зависимостей).
4. Запустите проект кнопкой Run на эмуляторе или телефоне.

Код приложения написан на Java. Для сборки нужен JDK 17 и Android SDK 35.
Если Gradle Wrapper отсутствует, Android Studio может предложить установленный локально Gradle.
